# Feedback and critique across three interface repairs

Twelve fresh implementers each repaired one synthetic page. Each of the workspace, nature walk and rehearsal briefs appeared once in each condition. All four implementations of a task started with identical HTML and source facts, equivalent tools, one submission and a four-minute allowance. Neutral IDs and execution order came from a shuffle. Three workers could run concurrently. The parent wrote the synthetic feedback and short critiques. Critiques described visible defects and omitted the later walk-order and rehearsal-print preferences. The briefs, rubric and scoring code predated delivery. An independent fresh reviewer received anonymous HTML copies, browser observations, the common original briefs and rubric. The reviewer had no assignment key. Scores were saved before analysis.

| Supplied inputs beyond brief and starter | Original checks | Preference matches |
|---|---:|---:|
| Neither | 12/12 | 1/6 |
| Critique | 12/12 | 1/6 |
| Feedback | 12/12 | 6/6 |
| Both | 12/12 | 6/6 |

On a two-item preference scale, averaging each factor over the other factor and all tasks yielded +1.67 items per page for feedback, 0 for critique and 0 for their interaction. All original scores reached the four-item ceiling. Each task showed the same feedback difference with or without critique. Workspace gained one item, walks and rehearsals each gained two. Both workspace runs without feedback already distinguished entrance windows from verified seat daylight.

The reviewer verified walk choices, browser controls, scheduled next-call behavior and print media where relevant. All 12 pages fit both phone widths. Only the two rehearsal runs with feedback supplied the requested print treatment and AM/PM times. Only the walk runs with feedback placed the access reminder first and sorted by distance.

Direct delivery of explicit preferences predicted their realization in these tasks. Critique had no observed effect on these measures. The original rubric covers facts, uncertainty, responsive fit and functional controls. Visual craft and user acceptance remain unmeasured. The explicit feedback closely matches the preference criteria by design. One build per task and condition leaves model variance within cells unknown. Retrieval is the actionable uncertainty for the next ablation: give every run the same preference history and vary whether the workflow points to its location, recording whether the agent finds and applies the relevant preference.
