# Sources and adaptation

Adapted from Matt Pocock [prototype](https://github.com/mattpocock/skills/blob/4ae2317ddb22b046e26455e4f9c9b3aaaf62212d/skills/engineering/prototype/SKILL.md), including [logic](https://github.com/mattpocock/skills/blob/4ae2317ddb22b046e26455e4f9c9b3aaaf62212d/skills/engineering/prototype/LOGIC.md) and [UI](https://github.com/mattpocock/skills/blob/4ae2317ddb22b046e26455e4f9c9b3aaaf62212d/skills/engineering/prototype/UI.md) references.

Retained one explicit question, disposable scope, observable state, scratch data, and preserving the answer with its evidence. Broadened beyond logic/UI to bounded feasibility probes. Removed mandatory HTML, variant count, UI routes, prototype branches, automatic commits, and production promotion. Replaced the blanket no-tests rule with checks needed to trust the experiment and protect data. Added predeclared decision rules, bounded attempts, real-versus-simulated evidence, inconclusive/not-run outcomes, and short human output. No upstream UI implementation, runtime, or subskill is bundled.
