# Sources and adaptation

Adapted from Superpowers [receiving-code-review](https://github.com/obra/superpowers/blob/22f0b463e7a5e579904dd6211a520321035526f7/skills/receiving-code-review/SKILL.md).

Retained technical evaluation before acting, evidence-backed disagreement, checks after fixes, and attention to scope. Removed personal response prohibitions, implicit GitHub replies, and a blanket halt when any item is unclear. Independent authorized work can continue while dependent findings await clarification. Added current-state checks, explicit per-finding dispositions, public-consumer uncertainty, finding-versus-remedy distinction, and separation of technical resolution from reviewer acceptance. No upstream code or required subskill is bundled.
