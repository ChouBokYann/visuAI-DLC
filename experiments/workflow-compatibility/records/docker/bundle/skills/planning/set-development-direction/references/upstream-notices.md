# Sources and adaptation

This is a selective adaptation, not an unchanged upstream workflow. All sources and their root MIT licenses were inspected at the revisions below.

- pstack, commit `4161d4ef5051574e825ffe70e2f43a2e49e4b3db`: [laziness protocol](https://github.com/backnotprop/pstack/blob/4161d4ef5051574e825ffe70e2f43a2e49e4b3db/skills/principle-laziness-protocol/SKILL.md) supplies smallest-change and consolidated-decision principles; [architect](https://github.com/backnotprop/pstack/blob/4161d4ef5051574e825ffe70e2f43a2e49e4b3db/skills/architect/SKILL.md) supplies grounding in existing systems and reconsideration when implementation exposes a poor fit. Omitted mandatory multi-model design, sketches with placeholder code, automatic implementation, and runtime dependencies.
- Matt Pocock, commit `4ae2317ddb22b046e26455e4f9c9b3aaaf62212d`: [codebase-design](https://github.com/mattpocock/skills/blob/4ae2317ddb22b046e26455e4f9c9b3aaaf62212d/skills/engineering/codebase-design/SKILL.md) informs useful small interfaces and observable behavior. Omitted mandatory vocabulary, speculative restructuring, and parallel interface-design workflows. Detailed ticket slicing and prototype execution are not bundled.
- ECC, commit `d2ef2680594f9a17526a6e1a2e18b3d242c5d17b`: [planner agent](https://github.com/affaan-m/ECC/blob/d2ef2680594f9a17526a6e1a2e18b3d242c5d17b/agents/planner.md) informs relevant codebase patterns, constraints, and risk identification. Omitted comprehensive phases, detailed file actions, estimates, example targets, and the agent's model binding.
- Superpowers, commit `22f0b463e7a5e579904dd6211a520321035526f7`: [writing-plans](https://github.com/obra/superpowers/blob/22f0b463e7a5e579904dd6211a520321035526f7/skills/writing-plans/SKILL.md) informs preserving decisions an implementer cannot infer and proportionate detail. Exact signatures, tests, commands, task-by-task plans, runtime selection, and additional approval rounds are not adopted here.

The lean stage boundary, first-increment handoff, stable concept references, uncertainty and acceptance distinctions, in-place revision, minimal frontmatter, and two-sentence human update are project-specific additions. No upstream helper or executable code is copied. No ontology validator is delivered.
