# Sources and adaptation

Original project wording informed by these pinned upstream principles:

- [Superpowers brainstorming](https://github.com/obra/superpowers/blob/22f0b463e7a5e579904dd6211a520321035526f7/skills/brainstorming/SKILL.md): context-first discovery and a brief implementers can act on. [Visual companion](https://github.com/obra/superpowers/blob/22f0b463e7a5e579904dd6211a520321035526f7/skills/brainstorming/visual-companion.md): use visual comparisons only when seeing clarifies the choice. No server scripts, mandatory commit or extra approval workflow copied.
- [BMAD UX](https://github.com/bmad-code-org/BMAD-METHOD/blob/e435a22574fe55722841086e5566420178b98df3/skills/method/bmad-ux/SKILL.md): distinguish appearance from behavior, inherit the existing UI system, expose assumptions and hand off design intent. Adapted into sections of one existing brief; no BMAD runtime, two-document requirement, memory scripts or mandatory agent dispatch.

Impeccable 4.4.0 and the locally installed design-taste-frontend skill were inspected only as potential downstream consumers. Their code and implementation instructions are not copied. No assertion of machine-readable compatibility or exact external TasteUI repository identity is made. The user's direction governs specialist defaults.
