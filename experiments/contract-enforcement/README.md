# Skill/contract/enforcement ablation pilot

Owner ChouBokYann, 2026-11-23. User authorized the proposed next step after skill-contract-enforcement research. Local prototype and comparison only; no canonical skill changes, independent maintainer approval, GitHub publication or adoption on main claimed. Related exploration/verification work remains separate. This protocol records ownership and acceptance before execution.

Four conditions, same source facts/workflow baseline/runtime tools/budgets: A current skills; B candidate action-oriented wording; C B plus structured work.json and local schema/reference validation; D C plus runner-observed receipt and host completion gate. Graphify disabled. Two paired tasks per condition: repair the study-space finder, then a fresh worker adapts its arm's result to solo silent work using its saved memory. Eight fresh agent runs, no repeated sampling of the same task; descriptive pilot, not statistical evidence. Transfer reuses code as well as memory, with no no-memory control, so no learning-efficiency claim.

Parent owns this protocol, preparation, schema/controller/oracle/tests and output/contract-enforcement. Workers own only assigned build/transfer app.mjs,index.html,DELIVERY.md,MEMORY.md, local tests/screenshots and work.json when applicable. No source, controller, other-arm or grader reads/edits. Source/snapshot/receipt boundaries are instructional under the shared filesystem, not an OS security boundary. No external services, installs, provider purchases, hooks, deployment or Git mutation. Reuse installed jsonschema, Python, Node, existing Playwright/Chromium; record versions. Normal host inference still applies.

First test controller rejection of malformed/missing records, broken source refs, omitted required coverage, unknown/fabricated/altered receipts, stale app/data/requirements/checker state, failed/empty/missing check groups and mutation during a run. Include valid control and structurally valid but unsupported action to show semantics are not proven. Observe tests fail before controller implementation, then pass. Execute actual runner against defective starter: negative result must block. Freeze inputs, candidate wording, schema/controller/oracle before agents.

All workers may invoke the same black-box runner and inspect its diagnostic output, or use their own checks; none may inspect the oracle source. C/D may invoke structural validation. D must reference a real receipt before requesting completion. Parent independently evaluates all final artifacts; for D it also invokes completion. A rejected D completion returns only gate diagnostics, at most one retry within the remaining six-minute wall/three-correction-round budget. Other arms receive no evaluator feedback. This host feedback difference is the intended enforcement treatment, not hidden coaching. Timeouts retain incomplete artifacts. No additional allowance from transfer or gate redispatch within a task.

Primary measures: required behavior and grounded labels, current-vs-obsolete feedback application, repeated failures, unsupported completion claims, and gate/worker verdict difference. Secondary: round count and approximate wall observations; do not invent token/tool cost. Independent same-day matching boundary/unknown cases, selected details/contact, no invented stairs, text integrity and 390/1280 browser checks are fixed before runs. Inspect screenshots separately. A valid receipt proves only the fixed oracle on a recorded state; whole visual quality and human acceptance remain outside it.

Prototype work.json is a small execution view referencing existing requirement/source concepts; it is not a replacement for authoritative Markdown/YAML or a new canonical ontology. Evidence_ref is runner output, not an agent-authored passed field. The controller hashes product/input state, contract content excluding evidence_ref, and its own/oracle/schema bytes. It records a ledger hash for receipts. With the same filesystem privilege an adversarial agent could alter the ledger/controller; no tamper-proof attestation is claimed. No JSON-supplied shell command executes. A future real integration needs a host-owned boundary; this experiment's parent acts as that host.

Stop after the comparison and report which mechanism adds value, including overblocking or overhead. Preserve failures, do not repair losing arms or promote a candidate without evidence. Removing these experiment/output paths reverses this addition. No unresolved user choice blocks this bounded test.
