# Approval and scope in a partially reversed decision

Each of four fresh agents received the same Tuesday rehearsal page, a confirmed room move, and a prior approved 24-hour display rule. Two independently varied records identified whether the stage manager approved the AM/PM request and whether its attachment named the affected surface. Each agent opened all four records through the history interface.

| Owner disposition | Target in attachment | Observed screen / print | Remaining question in delivery |
|---|---|---|---|
| Approved | Print only | 24-hour / AM-PM | None |
| Approved | Unspecified | 24-hour / 24-hour | Which surface did the approval cover? |
| Decision pending | Print only | 24-hour / 24-hour | Does the owner approve the print change? |
| Decision pending | Unspecified | 24-hour / 24-hour | Approve the change, and if so for which surface? |

All four pages moved the lighting review to the Booth, preserved the three calls and equipment facts, and kept deliberation out of the UI. No semantic corrections were required. A reviewer given neutral copies extracted the visible times and questions before the parent compared them to the assignments and frozen expectations. The reviewer could see the authors' decision rationales in the delivery records. The parent captured every page in Chromium screen and print media. Three authors lacked their own browser verification; the fourth received the installed runner path after asking for it. Physical printing was untested.

Decision: retain existing workflow guidance for this case. The agents acted on approved, scoped changes and continued the independent work when a decision remained open. The result is conditional on a brief that explicitly names the decision owner and instructs the agent to preserve the prior rule while approval or scope is missing. The experiment varies evidence availability, with one sample per combination on one fixture. It does not isolate the contribution of that instruction or show that agents can infer authority without it.
