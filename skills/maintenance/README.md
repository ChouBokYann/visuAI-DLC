# Maintenance

Skills for operating delivered software, diagnosing incidents, fixing defects, updating dependencies, and making ongoing improvements.

## Candidate skill

- [Diagnose issue](diagnose-issue/SKILL.md): characterize an observed problem, test focused hypotheses, and recommend the smallest supported response. Preserve uncertainty, distinguish mitigation from resolution, and reuse existing Implementation/Verification/Deployment responsibilities for fixes and releases.

Already justified maintenance changes can enter Implementation directly. This candidate does not introduce background monitoring, an incident platform, or an automatic dependency-upgrade programme. Independent maintainer review and real-project testing remain pending.
