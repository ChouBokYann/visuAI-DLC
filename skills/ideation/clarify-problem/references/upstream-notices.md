# Source and adaptation

Source: [Superpowers brainstorming](https://github.com/obra/superpowers/blob/22f0b463e7a5e579904dd6211a520321035526f7/skills/brainstorming/SKILL.md), commit `22f0b463e7a5e579904dd6211a520321035526f7`, Jesse Vincent.

This is a scoped adaptation, not a verbatim copy. Retained: understand the user's need before proposing a solution, read available context before questioning, ask questions that affect the work, and scale discovery to the uncertainty.

Changed: ends at a research-ready problem brief; explicitly distinguishes reported facts, evidence, and assumptions; maintains one brief; adds a one- or two-sentence human update and a minimal OKF-compatible output template. Omitted: solution-design process, mandatory design document, visual companion, reviewer fanout, and automatic routing to implementation planning. These changes keep the skill independently usable in the product Ideation workflow.

OKF reference: [Open Knowledge Format v0.2 specification](https://github.com/GoogleCloudPlatform/open-knowledge-format/blob/main/SPEC.md). The template uses its standard metadata conventions; no OKF implementation or semantic validator is bundled. No prose is adapted from the other candidate repositories in this skill.
