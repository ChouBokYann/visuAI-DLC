# Ideation

Skills for exploring problems, opportunities, users, and intended outcomes before committing to a solution.

## Candidate skills

- [Clarify problem](clarify-problem/SKILL.md): turn an unclear need into a sourced problem brief and a short human update. Skip the interview when the input already suffices. Candidate implementation; independent maintainer review is pending.
- [Research solutions](research-solutions/SKILL.md): investigate existing capabilities and integration constraints, preserving sources, uncertainty, and a concise human update. Candidate implementation; independent maintainer review is pending.
- [Recommend solution](recommend-solution/SKILL.md): compare known options, recommend the simplest sufficient approach, and distinguish proposals, conditions, and actual user decisions. Candidate implementation; independent maintainer review is pending.
- [Define requirements](define-requirements/SKILL.md): translate a selected or provisional direction into bounded, sourced requirements and observable acceptance conditions for Planning. Candidate implementation; independent maintainer review is pending.

Use the [Ideation workflow](../../docs/workflows/ideation.md) to choose an entry point and coordinate handoffs. Load only the skill needed next; each candidate remains independently callable. The workflow is documented guidance, not an installed runtime or automatic scheduler; independent maintainer review remains pending.

Try the candidates in another project with the [Codex setup and invocation guide](../../docs/workflows/ideation-codex.md). Installation is project-local and optional.

Add individual skills as `<skill-name>/SKILL.md`.

## Optional supplements

- [Clarify domain model](clarify-domain-model/SKILL.md): resolve business terms or rules whose ambiguity changes behavior; skip when existing definitions suffice.
- When evidence needs an experiment, use Implementation's canonical [Test an assumption](../implementation/test-an-assumption/SKILL.md). A prototype does not establish product readiness.

These are independently callable branch candidates, not added mandatory Ideation steps. See the [supplement proposal](../../docs/proposals/skill-supplements.md) and [second-batch walkthrough](../../docs/proposals/supplements-second-batch-walkthrough.md).

- [Understand expectations](understand-expectations/SKILL.md): define purpose-specific quality, observable must-haves and a finite refinement budget. Optional branch candidate; independent review and real-project trial pending.
