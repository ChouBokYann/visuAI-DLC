# Ideation

Skills for exploring problems, opportunities, users, and intended outcomes before committing to a solution.

## Candidate skills

- [Clarify problem](clarify-problem/SKILL.md): turn an unclear need into a sourced problem brief and a short human update. Skip the interview when the input already suffices. Candidate implementation; independent maintainer review is pending.
- [Research solutions](research-solutions/SKILL.md): investigate existing capabilities and integration constraints, preserving sources, uncertainty, and a concise human update. Candidate implementation; independent maintainer review is pending.
- [Recommend solution](recommend-solution/SKILL.md): compare known options, recommend the simplest sufficient approach, and distinguish proposals, conditions, and actual user decisions. Candidate implementation; independent maintainer review is pending.

Define requirements remains a proposed workflow step, not an implemented skill. Enter at the step appropriate to the user's existing context; clarification is not a mandatory restart.
