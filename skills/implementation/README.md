# Implementation

Detailed planning and execution in short cycles: plan the next useful increment, implement it, check the result, and adjust within the selected direction.

## Candidate skill

- [Implement increments](implement-increments/SKILL.md): carry authorized work through bounded changes with behavioral checks, current evidence, and a concise handoff. A full upfront task plan is not required. Independent maintainer review and real-project testing remain pending.

Reuse the existing delivery record and requirement/decision references. Local details stay in the implementation loop; changed direction or material constraints return to the affected Planning/Ideation decision. Completion prepares a Verification/review handoff, not a merge or release.
