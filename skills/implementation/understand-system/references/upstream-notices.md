# Sources and adaptation

Selective adaptation, not a copied upstream workflow. No executable helper or required external runtime is bundled.

- pstack [how](https://github.com/backnotprop/pstack/blob/4161d4ef5051574e825ffe70e2f43a2e49e4b3db/skills/how/SKILL.md), including its explorer/explainer references. Retained bounded flow tracing, source pointers, boundaries, and unresolved questions. Removed required model settings, subagents, and full explainer output in chat.
- ECC [codebase-onboarding](https://github.com/affaan-m/ECC/blob/d2ef2680594f9a17526a6e1a2e18b3d242c5d17b/skills/codebase-onboarding/SKILL.md). Retained entry-point discovery, representative data flow, and observed conventions. Removed automatic CLAUDE.md creation, two mandatory output artifacts, and whole-repo onboarding for narrow questions.

Project additions: evidence kinds and inspected state, documented versus inferred rationale, optional existing-record template, and a short human update. Other catalogued explanation skills were not copied.
