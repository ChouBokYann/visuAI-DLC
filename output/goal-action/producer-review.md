# Producer review

Both handoffs satisfy the four preregistered producer criteria: concrete inferred conditions with reasons; source/goal and interpretations; honest unknowns; bounded scope without booking/accounts/payment.

G derives whole-session containment, prerequisite identifiers, positive known capacity, waitlist semantics, and five eligible baseline classes. It explicitly retains unknown access without excluding classes when access is not required. It adds an earliest-start first-contact suggestion, labelled as a default rather than a resident preference. This is a discretionary recommendation, not a source fact, and may add unnecessary direction. Its brief is more tied to the baseline catalogue than D's.

D derives the same baseline outcomes, plus explicit precedence of definite failure over uncertainty, access eligibility for changed requirements, and recomputation from current facts. It includes mutation examples for time, capacity, prerequisites and access. This is a stronger explicit change-oriented contract, but is not yet evidence of better implementation.

Both mention producer sources that the consumer is prohibited from opening. Consumers independently receive the original request and source facts; the experiment does not depend on reading those extra packets.

Assessment is by the parent, unblinded. No feedback from this review is sent to either consumer.
