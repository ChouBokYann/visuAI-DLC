# Proposal: coordinate agent work with a bug-fix trial

## Change and lifecycle process
Add skills/implementation/coordinate-agent-work/SKILL.md in the existing lifecycle format; link from Implementation, the skills index, deliver-change and the engineering router. Add Experiment05 under experiments/coordinate-agent-work-bugfix.

## Problem and need
Perry wants reusable coordination like pstack. The existing engineering router has ownership/integration guidance but no discoverable canonical skill for dispatch, returned evidence, repair and independent retest. Previous shortlist reviews passed, so the repair handoff was not exercised.

## Proposed solution
Promote and strengthen the router's guidance into one skill with scoped assignments, one writer per shared area, source-linked results, finding dispositions, review handoffs and cleanup. Test instructions with fresh paper probes and exercise the skill through an actual seeded bug in a new café copy.

## Scope
Included: new skill/notices, navigation links, shortened router handoff section, this record, new Experiment05 and experiment index entry. Excluded: previous experiments and their evidence, main/first-iteration edits, installing a runtime, production, paid services, automatic publication or changes to other skills.

## Alternatives and tradeoffs
Keep inline router guidance (less discovery), copy all pstack orchestration (host/model assumptions and unnecessary complexity), or extract one host-independent skill (selected by the user's proceed request). One writer plus a reviewer fits the coupled storage fix; parallel writers would add conflict without independent work.
